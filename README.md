# Al-Game-playing-project
game of Gomoku (Five in a Row) The goal of Gomoku is for a player to get five of their marks in a row (horizontally, vertically, or diagonally) on a game board before the other player.  This project has two main parts:   a. Human vs. AI: using Minimax algorithm.   b. AI vs. AI The Minimax algorithm against the Alpha-Beta pruning algorithm.
